# Repository rules

## Update the "last updated" date before every commit

`src/components/Home.js` renders a small "last updated" line on the home page
(styled via `.last-updated` in `src/components/styles/Home.css`). Before
creating any commit that changes tracked files, update that date to the
current date, formatted as `Month DD, YYYY` (e.g. `May 08, 2026`).
